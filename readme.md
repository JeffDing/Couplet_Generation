# 新春对联生成器

## 项目简介

这是一个基于AI的新春对联生成系统，通过调用大语言模型API自动生成符合传统规范的新春对联。系统采用前后端分离架构，提供精美的可视化界面，模拟真实对联的卷轴效果。

## 功能特性

### 核心功能
- **AI智能生成**：基于大语言模型自动生成新春对联
- **格式验证**：自动验证对联格式，确保上下联字数相同、内容完整
- **重试机制**：最多尝试5次生成，确保输出符合要求的对联
- **实时预览**：生成后立即在页面上展示对联效果

### 界面特色
- **仿真卷轴设计**：模拟真实对联的红色卷轴外观
- **传统中国风**：采用红色、金色为主色调，营造春节氛围
- **竖排文字**：上下联采用传统竖排方式展示
- **动画效果**：文字逐字淡入动画，增强视觉体验
- **响应式布局**：支持PC端和移动端自适应显示

## 技术架构

### 后端技术
- **Flask**：轻量级Web框架
- **Flask-CORS**：跨域资源共享支持
- **Requests**：HTTP请求库，用于调用AI API

### 前端技术
- **HTML5 + CSS3**：页面结构与样式
- **原生JavaScript**：前端交互逻辑
- **Google Fonts**：使用"马善政"和"ZCOOL小薇"中文字体

## 核心模块说明

### 1. 后端API (app.py)

#### 主要接口
- `GET /`：主页，返回对联生成界面
- `POST /api/generate`：生成对联接口
- `GET /api/health`：健康检查接口

#### 核心函数
- `call_ai_api(prompt)`：调用AI模型API生成内容
- `parse_couplet(response_text)`：解析AI返回的对联文本
- `validate_couplet(upper, lower, horizontal)`：验证对联格式
  - 检查上下联字数是否相同
  - 验证字数范围（4-15字）
  - 验证横批长度（2-8字）
  - 检查是否为纯中文字符
- `generate_couplet()`：对联生成主流程，包含重试逻辑

### 2. 前端交互 (main.js)

#### 主要功能
- `generateCouplet()`：触发生成对联请求
- `updateCouplet(upper, lower, horizontal)`：更新页面显示
- `addAnimation()`：添加文字动画效果
- `showError(message)`：显示错误提示

#### 交互特性
- 支持键盘快捷键（空格键/回车键生成对联）
- 加载状态遮罩提示
- 错误信息Toast提示
- 页面加载时自动检查API配置状态

### 3. 样式设计 (style.css)

#### 设计亮点
- **卷轴效果**：使用渐变、阴影、伪元素模拟真实卷轴
- **红纸纹理**：通过SVG滤镜添加纸张质感
- **金色装饰**：卷轴顶部、底部的金属装饰元素
- **福字倒贴**：中间"福"字旋转180度，寓意"福到了"
- **悬停效果**：文字悬停放大，增强交互感

## 对联生成规则

系统生成的对联遵循以下规范：
1. **字数要求**：上下联各5-12字，横批2-6字
2. **内容要求**：喜庆吉祥，适合春节使用
3. **格式要求**：严格遵循"上联、下联、横批"格式
4. **字符要求**：仅包含中文字符和中文标点

## 安装与运行

### 环境要求
- Python 3.7+
- 现代浏览器（支持ES6+）

### 安装步骤

1. 安装Python依赖：
```bash
pip install -r requirements.txt
```

2. 配置环境变量：
```bash
export API_URL="your_api_url"
export MODEL_NAME="your_model_name"
export API_KEY="your_api_key"
```

3. 启动服务：
```bash
python app.py
```

或使用启动脚本：
```bash
bash run.sh
```

4. 访问应用：
打开浏览器访问 `http://localhost:5000`

## 使用说明

1. 打开网页后，点击"生成对联"按钮
2. 系统会自动调用AI生成对联
3. 生成的对联将显示在卷轴上
4. 可重复点击生成新的对联
5. 支持使用空格键或回车键快捷生成

## 注意事项

- 使用前需正确配置API相关环境变量
- 系统会自动验证生成的对联格式，不符合要求会自动重试
- 最多尝试5次，如仍无法生成符合要求的对联会提示错误
- 建议使用Chrome、Firefox、Safari等现代浏览器访问
